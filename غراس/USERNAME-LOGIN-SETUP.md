# تفعيل تسجيل الدخول باسم المستخدم في غراس

هذا التحديث يضيف وظيفة Supabase Edge Function باسم `username-auth` وعمود `profiles.username`.

## قبل التفعيل
- لا تحذف حساب المدير الحالي ولا تغيّر بريده أو كلمة مروره.
- شغّل ملف SQL التالي مرة واحدة في Supabase SQL Editor:
  `supabase/migrations/20261108_username_login.sql`
- انشر الوظيفة من المسار `supabase/functions/username-auth/index.ts`.
- في إعدادات الوظيفة عطّل **Verify JWT** حتى تصل طلبات تسجيل الدخول غير المسجلة؛ الوظيفة تتحقق بنفسها من جلسة المدير في عمليات الإدارة.
- تأكد من وجود Secrets: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`.

## ربط المدير
بعد نشر الوظيفة، يسجّل المدير الدخول مرة واحدة ببريده الحالي وكلمة مروره الحالية، ثم يُنفّذ من الجلسة الموثّقة طلب `claim_manager_username` باسم `Mohammad Najib`. لا تُنفّذ عملية الربط على صفوف المديرين عشوائياً؛ الربط يتم للحساب الذي سجّل دخوله فعلياً.

## حسابات المعلمات
إنشاء المعلمة يستخدم `create_teacher` مع الاسم الكامل واسم المستخدم وكلمة المرور ورقم الهاتف الاختياري. البريد الداخلي الاصطناعي لا يُعرض للمستخدمة. لا تستخدم الوظيفة لإنشاء حسابات قبل تشغيل SQL ونشرها.

## اختبار
اختبر OPTIONS (يجب أن يعيد 200)، ثم ربط المدير، ثم تسجيل الدخول باسم المستخدم، ثم إنشاء معلمة تجريبية. لا تغيّر واجهة تسجيل الدخول الأساسية إلى اسم المستخدم قبل نشر الوظيفة واختبارها بنجاح.
